# S2S Vocabulary CMS

A simple vocabulary content management system for the S2S project.

## Features

- Add, list, update, and delete vocabulary entries
- Manage term, category, definition, and example sentence
- Simple built-in browser UI served from the same Node.js server
- JSON API for integration with other tools

## Run locally

npm install
npm start

Then open http://localhost:3000

## Test

npm test
